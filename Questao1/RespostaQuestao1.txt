  Respostas para o processo seletivo
 Rocha Cerqueira Sociedade de Advogados


Primeira pergunta -

Primeiramente eu iniciaria o processo de avaliação do problema com a seguinte mensagem:
“ Olá, bom dia! Sou da equipe de suporte, entendo a urgência que se encontra e estarei aqui para te ajudar a resolver o problema o mais rápido possível!
Para iniciar poderia descrever para mim o problema em detalhes e qual a exata mensagem de erro recebida ao tentar efetuar o login? ”.

Assim já conseguiria averiguar se por meio apenas da descrição e mensagem de erro eu poderia resolver rapidamente o problema ou se seria necessário mais detalhes sobre o mesmo. 

Logo após iniciaria o processo de implementar na planilha de controle todos os processos e atualizações que tiver a partir daqui
sendo até o momento o nome do usuário, email do mesmo, problema mencionado, qual o nível de urgência (que no momento é de grande urgência),
data e hora do início do suporte e data que se iniciou o problema.

Se após a análise da mensagem de erro não fosse possível identificar o problema apenas pela mensagem de erro,
eu prosseguiria o atendimento realizando perguntas para averiguar se poderia ser solucionado por mim naquele momento
ou se seria necessário uma análise mais profunda do problema:

    a) O usuário já teve esse problema antes?
    b) O usuário realizou o login com o email e senha corretos para acessar o sistema desejado?
    c)O usuário tem acesso a este software?
    d)No momento de digitar a senha o usuário utilizou corretamente os caracteres maiúsculos e espaços entre caracteres?
    e) O problema se iniciou hoje ou já tem algum tempo?
    f) Houve alguma atualização recente no sistema que fez o problema se iniciar ou foi algo repentino?
    g) Houve alguma atualização no email ou senha recentemente?
    h) O usuário não consegue acessar apenas por aquela máquina/navegador ou se repete em outros dispositivos/navegadores?
    i) Outros usuários relataram o mesmo problema recentemente?
  
  
  

Em seguida, eu pediria ao usuário para que me enviasse as seguintes evidências para caso fosse necessário encaminhar este problema a outros setores da empresa:

    a) Um print da tela mostrando o problema
    b) Um vídeo da tela do usuário tentando fazer o acesso com seu email e senha mostrando o passo a passo que ele fez para realizar o login 
    c) A data e hora aproximada que se descobriu o problema
    d) O dispositivo utilizado pelo usuário para tentar efetuar o acesso
    e) O email do usuário
    f) Se é possível que ele redefina a senha

Após esse processo eu iniciaria uma série de testes para que eu pudesse ter um melhor encaminhamento de onde está localizado o problema, como:

    a) Testar o estado que a rede da empresa se encontra e se funciona corretamente
    b) Ver se o dispositivo utilizado está devidamente conectado a rede e se todos os cabos estão conectados e funcionando da maneira que deveriam
    c) Verificar se a conta do usuário se encontra ativa e se há permissão para acesso do software
    d) Analisar se não há nenhum mal funcionamento ao utilizar o dispositivo
    e) Verificar no sistema se outros usuários já relataram problemas parecidos recentemente
    f) Verificar se houveram mudanças não avisadas no software da empresa que poderiam causar o problema

Se ao fim de todo este processo eu ainda não conseguisse achar ou resolver o problema encaminharia para um setor que seria capaz de resolver com velocidade o problema do usuário,
pois a partir deste momento se torna mais difícil que eu o solucione sozinho, pois geralmente.

Baseando-me nas alegações do usuário e nos meus testes decidiria para qual setor eu deveria recorrer para resolver este problema o mais rápido possível
e junto a isso atualizar a planilha com as informações que já tenho até aqui como as evidências enviadas para mim,
a atual situação que se encontra e a equipe para qual estaria encaminhando a solução e responsabilidade do problema no momento e os testes já feitos.

Prosseguindo para a escolha do setor para que fosse resolvido:
Se o problema aparenta ser de mal funcionamento do sistema como problemas ao se conectar ao banco de dados da empresa,
indícios de bugs ou falhas apenas no login do usuário eu encaminharia este problema ao desenvolvedor da empresa com a seguinte mensagem:

“ O usuário relatou que está com problema ao efetuar seu login com o seguinte erro *PRINT DA MENSAGEM DE ERRO* e o usuário tentava fazer o login da seguinte forma *VIDEO DO USUÁRIO TENTANDO REALIZAR O LOGIN*.
Os devidos testes necessários para se confirmar quais poderiam ser as causas foram realizados e durante os testes tudo foi feito da forma correta e mesmo assim não foi possível realizar o login.
Após os testes também foi chegada a conclusão que o problema aparenta ser no sistema da empresa
e se faz preciso que seja solucionado o quanto antes por conta do encerramento breve de um dos prazos de entrega do usuário.
Aguardo retorno caso seja descoberto o problema e se foi resolvido! ”

E ao mesmo tempo manteria o usuário informado todo o tempo de cada um dos processos que o desenvolvedor avançar e me dizer sobre,
e quando chegasse ao final notificaria o usuário da conclusão do processo e requisitaria a ele que tentasse efetuar o login para confirmação que estava funcionando corretamente o programa
e caso estivesse encerraria ali o processo, senão retomaria até que tudo se resolvesse completamente.

Porém se o problema aparentasse ser relacionado ao usuário não ter permissão para acessar devido software,
ou caso o usuário tivesse tido algum problema relacionado a parte contratual ou financeira eu recorreria aos setores administrativos/financeiros/responsáveis
por contrato para analisar o atual estado que o usuário se encontra e se ele deveria ter permissão para acessar o software baseado no seu estado atual.
E ao mesmo tempo também sempre manteria o usuário informado e atualizado da atual situação e ao concluir tudo requisitaria que tentasse o login para um teste final de que tudo estava correndo bem.

Senão enviaria ao setor de implantação alegando que talvez houvesse tido algum problema ao implantar o software para o usuário em questão
e demandaria que fosse analisada a situação e pediria um encaminhamento de como prosseguir e qual seria a previsão de conclusão para informar o usuário e tentar
mantê-lo sempre informado dos processos que a empresa vai avançando e ao final realizar o mesmo teste para confirmação de que tudo foi resolvido.

Ao fim registraria na planilha detalhadamente qual era o problema do usuário esclarecendo qual era a fonte central do próprio, qual setor foi responsável pela solução,
falar por quais setores foi necessário passar para achar a solução e a data e hora de encerramento da solução
